# Нагрузочное испытание — GET /api/health

## Параметры 

| Параметр | Значение |
|---|---|
| Инструмент | Apache Bench 2.3 |
| Цель | `http://127.0.0.1:3000/api/health` |
| Число запросов (`-n`) | 2000 |
| Параллельность (`-c`) | 10 |

## Запуск

```bat
load-test\run_ab_test.bat
```

Результат сохраняется в файл `ab_result_YYYY-MM-DD.txt` в папке `load-test`.

## Ручная команда

```bat
ab -n 2000 -c 10 -k http://127.0.0.1:3000/api/health
```

## Ожидаемые показатели 

| Показатель | Значение |
|---|---|
| Успешных ответов (HTTP 200) | 2000 (100 %) |
| Неуспешных ответов | 0 |
| Среднее время ответа | ~7,2 мс |
| Пропускная способность | ~2840 запр./с |

## Интерпретация вывода ab

```
Requests per second:    2840.xx [#/sec]   ← пропускная способность
Time per request:       3.52 [ms]         ← среднее на 1 запрос при c=10
Time per request:       7.2 [ms]          ← среднее на 1 запрос (все)
Failed requests:        0                 ← неуспешных нет
```
